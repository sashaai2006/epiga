# Настройка гиперпараметров классификатора методом NSGA-II

Проект содержит самостоятельную реализацию **варианта 10 лабораторной работы № 3 (трек A)**: подбор гиперпараметров модели классификации по трём конкурирующим критериям — максимум качества, минимум времени обучения, минимум числа параметров.

Реализован алгоритм NSGA-II с нуля: недоминируемая сортировка, расстояние до скопления, турнир по рангу и скоплению, SBX-кроссовер, полиномиальная мутация и элитизм объединённой популяции. Модель классификатора (нейросеть с одним скрытым слоем, softmax, кросс-энтропия, мини-батчевый градиентный спуск с L2) также реализована вручную на `numpy`. Готовые пакеты оптимизации и машинного обучения не используются.

## Структура проекта

- `tuning_nsga2.py` — генерация данных, модель, критерии, операторы, NSGA-II, ГА со взвешенной суммой и случайный поиск.
- `01_genetic_algorithm.ipynb` — постановка задачи, данные, критерии, операторы, одиночный запуск и фронт Парето.
- `02_experiments.ipynb` — 5 серий по 20 запусков, статистика, графики, блок-схема и характерные решения.
- `configs/` — параметры алгоритма в JSON.
- `results/` — результаты каждого запуска, сводная статистика, лучший фронт и характерные решения.
- `plots/` — графики сходимости, сравнение, фронт Парето и блок-схема.
- `report.md` — полный отчёт с формулами, таблицами и выводами.
- `../formulas.md` — общие требования и формулировка задания.

Команды запуска нужно выполнять из каталога `lab3/`: ноутбуки импортируют `tuning_nsga2.py` и используют относительные каталоги результатов.

## Установка

Требуется Python 3.10+. Общее окружение находится в корне репозитория.

С установленным `uv`:

```bash
uv venv ../venv
source ../venv/bin/activate
uv pip install -r ../requirements.txt
```

Без `uv`:

```bash
python3 -m venv ../venv
source ../venv/bin/activate
python -m pip install -r ../requirements.txt
```

## Запуск в Jupyter

```bash
cd lab3
source ../venv/bin/activate
jupyter notebook
```

Откройте `01_genetic_algorithm.ipynb` и выберите **Run All**, затем так же выполните `02_experiments.ipynb`. Второй ноутбук самостоятельно импортирует модуль и повторно генерирует фиксированный набор данных.

## Запуск из командной строки

Из каталога `lab3/`:

```bash
source ../venv/bin/activate
jupyter nbconvert --to notebook --execute --inplace 01_genetic_algorithm.ipynb
```

## Постановка задачи

Генотип — пять гиперпараметров: число нейронов скрытого слоя (0–16, 0 — линейная модель), логарифм скорости обучения (−3…−1), число эпох (5–150), коэффициент L2 (0–0.05) и логарифм размера батча (32/64/128). Критерии (все минимизируются):

| Критерий | Смысл |
| --- | --- |
| f1 | ошибка классификации на тестовой выборке |
| f2 | стоимость обучения = эпохи × число батчей × число параметров (детерминированный прокси времени) |
| f3 | число обучаемых параметров модели |

Данные — синтетическая классификация (3 класса, 10 признаков, 800 объектов, смесь гауссовых облаков) с фиксированным `data_seed = 202610`; разбиение на обучение (560) и тест (240) фиксировано. Порядок перемешивания батчей при обучении также фиксирован, поэтому оценка генотипа полностью воспроизводима.

## Параметры

| Параметр | Значение |
| --- | ---: |
| Признаки / классы / объекты | 10 / 3 / 800 |
| `data_seed` | 202610 |
| Размер популяции | 60 |
| Бюджет оцениваний модели на запуск | 1000 |
| Кроссовер | SBX, η = 15, вероятность 0.9 |
| Мутация | полиномиальная, η = 20, вероятность гена 0.15 |
| Селекция | турнир по (ранг, расстояние до скопления) |
| Seed серий | 1000, …, 1019 |

Базовая конфигурация: `NSGAII_base`. Альтернативы меняют только один фактор: размер популяции (30) или вероятность мутации (0.3). Дополнительные серии — ГА над взвешенной суммой критериев (0.6/0.2/0.2 в нормированных координатах) и случайный поиск; бюджет у всех серий одинаковый.

Качество результата запуска измеряется гиперобъёмом фронта Парето архива всех оценённых решений относительно фиксированной опорной точки (1.01; 1.1·макс. стоимость; 1.1·макс. число параметров). Первая координата больше любой достижимой ошибки (ошибка лежит в [0, 1]), поэтому в гиперобъём участвуют все допустимые решения, а точки за пределами опорной области отсекаются перед интегрированием.

## Результаты

После выполнения ноутбуков создаются:

- `results/<серия>.csv` — 20 строк на серию: seed, гиперобъём, размер фронта, лучшая ошибка, минимальная стоимость, число параметров, оценки, время;
- `results/summary.csv` и `summary.json` — best, mean, median, std, worst по гиперобъёмам серий;
- `results/all_results.json` — полные истории сходимости и фронты;
- `results/best_front.csv` — фронт Парето лучшего запуска серии NSGA-II;
- `results/representative_solutions.csv` — три характерных решения («быстрое», «сбалансированное», «точное») в декодированной форме;
- `plots/convergence.png`, `comparison.png`, `pareto_front.png`, `algorithm_flowchart.png`;
- `configs/*.json` — параметры конфигураций.

Подробный анализ и выводы приведены в [report.md](report.md).

## Воспроизводимость

Все случайные процедуры используют `numpy.random.default_rng` с явным seed. Набор данных генерируется с seed 202610, независимые запуски — с seed 1000–1019. Обучение модели детерминировано при заданном генотипе: генератор перемешивания батчей инициализируется `data_seed`, а не seed запуска. Начальная популяция входит в бюджет, последнее поколение может быть неполным, поэтому каждый метод получает ровно 1000 оцениваний.

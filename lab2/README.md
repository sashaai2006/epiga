# План дежурств на неделю генетическим алгоритмом

Проект содержит самостоятельную реализацию генетического алгоритма для **варианта 10 лабораторной работы № 2**: составление плана дежурств 7 сотрудников на 21 смену с жёсткими ограничениями и учётом предпочтений.

Используются бинарная матрица $7\times21$, равномерный кроссовер по сменам, две мутации, турнирная селекция и элитизм. Реализованы и сравнены ремонт и штрафы, а также случайный допустимый поиск с тем же бюджетом. Готовые оптимизаторы не используются.

## Структура проекта

- `duty_ga.py` — генерация данных, ограничения, целевая функция, операторы, ремонт, ГА и baseline.
- `01_genetic_algorithm.ipynb` — постановка задачи, данные, четыре примера решений и одиночный запуск.
- `02_experiments.ipynb` — 4 серии по 20 запусков, статистика, графики, блок-схема и лучшее расписание.
- `configs/` — параметры алгоритма и исходный экземпляр в JSON.
- `results/` — результаты каждого запуска, сводная статистика, примеры и лучшее решение.
- `plots/` — графики сходимости, сравнение и блок-схема.
- `report.md` — полный отчёт с формулами, таблицами и выводами.
- `../formulas.md` — общие требования и формулировка задания.

Команды запуска нужно выполнять из каталога `lab2/`: ноутбуки импортируют `duty_ga.py` и используют относительные каталоги результатов.

## Установка

Требуется Python 3.10+. Общее окружение находится в корне репозитория.

С установленным `uv`:

```bash
uv venv ../venv
source ../venv/bin/activate
uv pip install -r ../requirements.txt
```

Без `uv`:

```bash
python3 -m venv ../venv
source ../venv/bin/activate
python -m pip install -r ../requirements.txt
```

## Запуск в Jupyter

```bash
cd lab2
source ../venv/bin/activate
jupyter notebook
```

Откройте `01_genetic_algorithm.ipynb` и выберите **Run All**, затем так же выполните `02_experiments.ipynb`. Второй ноутбук самостоятельно импортирует модуль и повторно генерирует фиксированный экземпляр.

## Запуск из командной строки

Из каталога `lab2/`:

```bash
source ../venv/bin/activate
jupyter nbconvert --to notebook --execute --inplace 01_genetic_algorithm.ipynb
jupyter nbconvert --to notebook --execute --inplace 02_experiments.ipynb --ExecutePreprocessor.timeout=1200
```

Полный набор экспериментов перезаписывает файлы в `results/`, `configs/` и `plots/`. В текущем окружении его выполнение занимает примерно полторы минуты.

## Параметры

| Параметр | Значение |
| --- | ---: |
| Сотрудники / дни / смены в день | 7 / 7 / 3 |
| Максимум смен на сотрудника | 4 |
| `data_seed` | 202610 |
| Размер популяции | 60 |
| Бюджет вычислений фитнеса | 6000 |
| Селекция | турнирная, $k=3$ |
| Вероятность кроссовера | 0.9 |
| Вероятность мутации каждой смены | 0.15 |
| Элитизм | 2 |
| Штраф за нарушение | 1000 |
| Seed серий | 1000, …, 1019 |

Базовая конфигурация: `constraint_handler="repair"`, `mutation="reassign"`. Альтернативы меняют только один из этих параметров.

## Результаты

После выполнения ноутбуков создаются:

- `results/<method>.csv` — 20 строк на метод: seed, фитнес, мягкая цель, допустимость, нарушения, нагрузка, бюджет и время;
- `results/summary.csv` и `summary.json` — best, mean, median, std, worst, доля допустимых и время;
- `results/all_results.json` — полные результаты и истории сходимости;
- `results/best_schedule.csv` — лучшее расписание в предметной форме;
- `results/best_solution.json` — бинарная матрица и метрики лучшего решения;
- `results/solution_examples.json` — два допустимых и два недопустимых примера;
- `plots/convergence_*.png`, `comparison.png`, `algorithm_flowchart.png`.

В сохранённой серии базовый ГА во всех 20 запусках получил мягкую цель **7** без нарушений. Подробный анализ и само расписание приведены в [report.md](report.md).

## Воспроизводимость

Все случайные процедуры используют `numpy.random.default_rng` с явным seed. Экземпляр генерируется с seed 202610, независимые запуски — с seed 1000–1019. Начальная популяция входит в бюджет, а последнее поколение может быть неполным, поэтому каждый метод получает ровно 6000 оцениваний.

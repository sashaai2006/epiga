# EPIGA

Репозиторий лабораторных работ по эволюционному программированию и генетическим алгоритмам.

## Лабораторные работы

- [Лабораторная работа № 1](lab1/README.md) — минимизация функции Михалевича генетическим алгоритмом. Реализация, эксперименты и [отчёт](lab1/report.md) готовы.
- [Лабораторная работа № 2](lab2/README.md) — составление плана дежурств на неделю генетическим алгоритмом, вариант 10. Реализация, эксперименты и [отчёт](lab2/report.md) готовы.
- [Лабораторная работа № 3](lab3/README.md) — настройка гиперпараметров классификатора методом NSGA-II, вариант 10, трек A. Реализация, эксперименты и [отчёт](lab3/report.md) готовы.

## Условия

Общие требования и условия работ находятся в [formulas.md](formulas.md).

## Требования и установка

Нужны Python 3.10+ и [`uv`](https://docs.astral.sh/uv/). Текущее окружение проверено с Python 3.14.3. Для создания окружения из корня репозитория выполните:

```bash
uv venv venv
source venv/bin/activate
uv pip install -r requirements.txt
```

## Быстрый старт

Ниже воспроизводится эксперимент ЛР2. Команды выполняются из корня репозитория:

```bash
source venv/bin/activate
cd lab2
jupyter nbconvert --to notebook --execute --inplace 01_genetic_algorithm.ipynb
jupyter nbconvert --to notebook --execute --inplace 02_experiments.ipynb --ExecutePreprocessor.timeout=1200
```

Второй ноутбук выполняет 4 серии по 20 запусков и перезаписывает результаты в `results/`, конфигурации в `configs/` и графики в `plots/`. Успешное выполнение можно проверить по сводной таблице:

```bash
python -c "import pandas as pd; print(pd.read_csv('results/summary.csv').round(3).to_string(index=False))"
```

Итоговое расписание сохраняется в `results/best_schedule.csv`, а его обоснование — в [отчёте ЛР2](lab2/report.md). Команды и параметры ЛР1 приведены в [отдельной инструкции](lab1/README.md).

## Воспроизводимость и ограничения

В обеих работах начальные значения генераторов случайных чисел задаются явно; серии используют seed 1000–1019. Бюджет ЛР1 составляет 10 000 вычислений функции, ЛР2 — 6000 вычислений фитнеса на запуск, ЛР3 — 1000 обучений модели на запуск. Параметры и полные результаты хранятся в каталогах `configs/` и `results/` соответствующей работы.

Это учебные реализации без готовых пакетов оптимизации. ЛР2 и ЛР3 используют синтетические данные с фиксированным seed 202610. Результаты являются лучшими найденными решениями, а не доказательством глобальной оптимальности.

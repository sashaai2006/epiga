# Минимизация функции Михалевича генетическим алгоритмом

Проект содержит самостоятельную реализацию генетического алгоритма для минимизации 9-мерной функции Михалевича:

$$f(x) = -\sum_{i=1}^{9} \sin(x_i)\left[\sin\left(\frac{i x_i^2}{\pi}\right)\right]^{20},\qquad x \in [0, \pi]^9.$$

Готовые оптимизаторы не используются. Пояснения к формулам, операторам и экспериментам находятся в Markdown-ячейках ноутбуков.

## Структура проекта

- `01_genetic_algorithm.ipynb` — функция, параметры, операторы ГА, случайный поиск и пример одного запуска.
- `02_experiments.ipynb` — серии из 20 запусков, статистика, графики и сохранение результатов.
- `configs/` — параметры экспериментов в JSON.
- `results/` — результаты запусков в CSV и JSON.
- `plots/` — графики сходимости и сравнения.
- `report.md` — отчёт по лабораторной работе.
- `../formulas.md` — общие требования и формулировки заданий.

Второй ноутбук выполняет первый через `%run`, поэтому файлы нужно хранить вместе, а команды запускать из каталога `lab1/`.

## Установка

Требуется Python 3.10+. Общее окружение находится в корне репозитория.

**Если `uv` уже установлен:**

```bash
uv venv ../venv
source ../venv/bin/activate
uv pip install -r ../requirements.txt
```

**Если `uv` нет, но вы хотите его установить:**

На macOS и Linux выполните:

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

На Windows (PowerShell):

```powershell
powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
```

После установки выполните команды из предыдущего блока.

**Если `uv` не нужен — обычный `pip`:**

```bash
python3 -m venv ../venv
source ../venv/bin/activate
python -m pip install -r ../requirements.txt
```

## Запуск в Jupyter

```bash
source ../venv/bin/activate
jupyter notebook
```

Откройте `01_genetic_algorithm.ipynb` и выполните все ячейки. Затем откройте `02_experiments.ipynb` и также выберите **Run All**. Второй ноутбук автоматически загрузит реализацию из первого.

## Запуск из командной строки

```bash
source ../venv/bin/activate
jupyter nbconvert --to notebook --execute --inplace 01_genetic_algorithm.ipynb
jupyter nbconvert --to notebook --execute --inplace 02_experiments.ipynb --ExecutePreprocessor.timeout=1200
```

Полный набор экспериментов перезаписывает файлы результатов и графиков.

## Параметры базовой конфигурации

| Параметр | Значение | Описание |
|---|---:|---|
| `dim` | 9 | Размерность пространства |
| `population_size` | 100 | Размер популяции |
| `budget` | 10 000 | Общее число вычислений функции, включая начальную популяцию |
| `selection` | tournament | Турнирная селекция |
| `tournament_size` | 3 | Размер турнира |
| `crossover` | sbx | SBX-кроссовер |
| `crossover_prob` | 0.9 | Вероятность кроссовера |
| `mutation_prob` | 0.1 | Вероятность мутации координаты |
| `mutation_sigma` | 0.1 | Начальное σ гауссовой мутации |
| `adaptive_sigma` | True в базовом эксперименте | Адаптация σ по улучшению лучшего значения |
| `adaptive_sigma_factor` | 1.01 | Множитель адаптации σ |
| `sbx_eta` | 15.0 | Параметр SBX |
| `elitism` | 1 | Число элитных особей |
| `seed` | 1000 | Начальное значение ГПСЧ первого запуска |

Значение `adaptive_sigma` по умолчанию в `GAConfig` равно `False`; в базовом эксперименте оно явно включено.

## Результаты

После выполнения второго ноутбука создаются:

- `results/*.csv` — лучший результат, seed и фактическое число вычислений для каждого запуска;
- `results/summary.csv` — best, mean, median, std и worst по сериям;
- `results/all_results.json` — полные результаты и конфигурации;
- `plots/convergence_*.png` — сходимость по числу вычислений функции;
- `plots/comparison.png` — сравнение конфигураций;
- `configs/*.json` — параметры конфигураций.

## Воспроизводимость

Каждая серия состоит из 20 независимых запусков с `seed = 1000, 1001, …, 1019`. ГА и случайный поиск используют одинаковый бюджет ровно в 10 000 вычислений функции. В альтернативных конфигурациях относительно базовой меняется только один параметр.
